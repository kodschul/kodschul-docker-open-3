# Fehlerbild 1 (Lab 7.1)

Hello-App aus Frontend (wird gebaut) und Backend (`backend:v1`).

```bash
docker compose up -d --build
```

- **Erwartet:** `http://localhost:8701` zeigt „Hello World 1.0.0" mit einer Backend-Antwort.
- **Beobachtet:** Die Seite lädt nicht.

Finde die Ursache, behebe sie in den Dateien dieses Ordners und starte erneut. Aufräumen: `docker compose down`.
