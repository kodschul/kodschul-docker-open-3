# Fehlerbild 2 (Lab 7.1)

Hello-App aus Frontend (wird gebaut) und Backend (`backend:v1`).

```bash
docker compose up -d --build
```

- **Erwartet:** `http://localhost:8702` zeigt „Hello World 1.0.0" mit einer Backend-Antwort.
- **Beobachtet:** Der Befehl bricht ab, es startet kein Container.

Finde die Ursache, behebe sie in den Dateien dieses Ordners und starte erneut. Aufräumen: `docker compose down`.
